# CloudBank Classroom

**CloudBank Classroom** is a cloud-hosted JupyterHub built for teaching. Each learner gets a modest
allocation of persistent storage, memory, and CPU, signs in with their existing campus credentials,
and lands in a JupyterLab environment that already has the common data science stack installed —
no local setup, no install day.

These docs cover how to use and run a CloudBank Classroom.

## Who this is for

- **Students** — logging in for the first time, finding your files, and getting help.
- **Instructors** — requesting a classroom, distributing materials, and managing your roster.

## About CloudBank

CloudBank is an NSF-funded service that simplifies access to commercial cloud resources for computer
science research and education. Learn more at [cloudbank.org](https://www.cloudbank.org/).
