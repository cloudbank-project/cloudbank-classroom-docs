# CloudBank Classroom

CloudBank Classroom is a cloud-hosted JupyterHub built for teaching. Each learner gets a modest allocation of persistent storage, memory, and CPU, signs in with their existing campus credentials, and lands in a JupyterLab environment. These docs cover how to use and run a CloudBank Classroom. 

:::{note}
These docs assume you already have access to a CloudBank Classroom. To request one, see [how to request access through ACCESS](https://www.cloudbank.org/training/access-cloudbank-classroom#toc-request-access-to-cloudbank-classroom-through-access) on the CloudBank site.
:::
